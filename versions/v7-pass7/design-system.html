Aquemi design system

Precise, quiet, finished.

Every token, component and page block on this page is read from design-system/ in the repository: the same files the website loads and the Claude design system is published from. Change a file there and this page, the site and the next Claude session all follow.

Working on the system

Change or extend it

Change a colour, size or space

Edit design-system/tokens.json, then rebuild. Every component and page updates.

python tools/design_system.py build

Adjust a component

Styles are in the component's style.css (built into bundle.css), rules in the component's README.md, the example in its preview.html. Each component below links to all three.

Add a component

Scaffold it, write the README and preview with real copy, style it with tokens only, then build and check.

python tools/design_system.py new PullQuote "Page sections"
python tools/design_system.py build
python tools/design_system.py check

With Claude

Open this repository in Claude Code and ask, for example, "add a comparison table component to the design system". CLAUDE.md gives the agent the workflow, including publishing to the Claude design system.
