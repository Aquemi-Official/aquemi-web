# Equipment drawings

Seventeen isometric line drawings of Aquemi equipment, one per system, service and industry page (`sys-pw.png`, `svc-cq.png`, `ind-pharma.png` …). Each is a transparent mask: show it with the Illustration component (`.aq-illustration` with `mask-image`), which paints the lines in a colour token so the drawing follows light and dark themes. Never show the PNG as a plain image or recolour it with a literal colour.

Use a drawing only for the page it depicts: the Hero figure on that page, a WaterPath stop or a LinkGrid/RelatedLinks card that links to it. Sources, prompts and the black-on-white originals live in the website repo under `design-system/inspiration/art/`.
