Page is the layout every Aquemi page, section and preview sits in: the container, the section rhythm and the type classes.

- Wrap a whole page in `<div class="aq-page">`. It sets the ground, the body type and a container query, so sections reflow when the page (not only the window) is narrower than 860 px.
- Each section is `<section class="aq-section">` holding `<div class="aq-in">` (content width `content-max`, side gutter `space-8`, `space-4` when narrow). Sections are separated by a `line` hairline.
- Stacks: `aq-stack` (gap `space-4`) for a heading with its lead; `aq-stack-l` (gap `space-8`) between a heading block and its content.
- Type classes, matching the type tokens: `aq-display-xl` (home hero only), `aq-display` (other heroes), `aq-h1` (section openers), `aq-h2`, `aq-h3` (item titles), `aq-lead` (one sentence under a heading), `aq-small` (descriptions, captions), `aq-eyebrow` (uppercase mono label above a heading).
- Order on every page: NavBar, Hero, content sections, a navy closing Band, Footer.
- Section headings are `<h2 class="aq-h1">`; the hero holds the only `<h1>`.
- **Section head** (`.aq-sec-head`, `wSecHead` in `assets/src/core.js`): the one way every section opens. Optional `aq-eyebrow` (names the system or standard), the `<h2 class="aq-h1">` (9 words or fewer), optional one-sentence `aq-lead` intro (35 words or fewer). Gap `space-3`. Every block renderer receives it as `H`; none prints its own heading, intro or a mono caption above its content.
  `<header class="aq-sec-head"><p class="aq-eyebrow">PURIFIED WATER · USP &lt;645&gt;</p><h2 class="aq-h1">Water quality you release against</h2><p class="aq-lead">…</p></header>`
- **Index** (`.aq-index`): the one numbering style. `01`, Geist Mono 13/24, `ink-subtle`, tabular figures, `aria-hidden="true"`, in the left column of a row. No `01 /`, no brackets, no ghost or outline numerals, no filled numbers, no `flow` numbers.
- **Rows** (`.aq-rows`, `wRow` in `core.js`): the one list grammar, used by OptionList, ProcessSteps and LinkGrid and mirrored by FAQ, DocList and RelatedLinks on phones. `<ol class="aq-rows">` of `<li>` each holding one `.aq-rows__row` (`<div>`, or `<a>` when the whole row links): `.aq-index`, `<h3 class="aq-rows__t">`, optional `<p class="aq-rows__d">`, optional `.aq-rows__art` drawing. Desktop: `index | title | line` (`space-12 | 4fr | 7fr`); phones: `index | title`, line below. `line` hairlines between rows; no boxes.
- **Rhythm:** sections sit on `surface`. At most one tinted band (`aq-band--sunken` or the limestone statement Band) in the middle of a page; `aq-band--navy` only for the closing. Grid paper only behind illustrations (hero drawing, diagrams), never behind reading text.
