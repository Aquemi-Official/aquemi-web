KeyFacts is a measurement strip of three to six figures, each with its unit and the standard behind it, that tells an engineer what a page stands on before they read a word of copy.

- Markup: `<dl class="aq-key-facts">` with one `<div>` per fact: `<dt>` (the parameter, "Conductivity at 25 °C"), then `<dd class="aq-key-facts__value">` (comparator `aq-key-facts__cmp`, figure `aq-key-facts__fig`, unit `aq-key-facts__unit`), then an optional second `<dd class="aq-key-facts__src">` (the standard, "USP <645>"). Keep `dt` first so screen readers read the name, then the value, then the source.
- On the site, `wKeyFacts(facts)` in `assets/src/parts/KeyFacts.js` builds it from page `facts` `{l, v}`: the label splits at the last " · " into name and source; the value splits off a leading comparator and a trailing unit (only when the tail after the last space has no digits and follows a figure, so "Part 11" and "[Ra, µm]" stay whole). Placeholders keep their `[brackets]`.
- Anatomy: a `line-strong` frame with tick rulers inside its top and bottom edge (minor ticks every `space-2`, major every `space-16`), `line` dividers between cells and round fixings where they meet the rulers. The "01 /" index is a CSS counter in `flow`, the name uses the eyebrow style in `ink-muted`. Figures are Geist Mono 300 in `ink`, tabular, 32 to 48 px (26 to 36 px from five facts on, 36 px on phones); the unit is set at about half size in `ink-muted`; the source is 12 px mono over a dashed hairline at the cell's foot.
- Rulers, fixings and index are CSS only and plot nothing. Below 860 px container width the cells stack as a vertical list with the same anatomy.
- On the site it sits at the bottom of the Hero (`facts` in `content/pages/`). Take every figure from the page's own spec table or copy; unconfirmed figures stay in `[square brackets]`. Write values exactly as the standard does, with the comparison sign.
- Not for one figure with an explanation: use Readout. Not for full specifications: use SpecTable.
