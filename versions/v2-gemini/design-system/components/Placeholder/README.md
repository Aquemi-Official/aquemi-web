Placeholder marks a fact only Aquemi can supply (a capacity, lead time, certificate, location, case-study figure) so an invented number never ships.

- Write it in square brackets: `<span class="aq-ph">[lead time in weeks]</span>`. The website wraps any `[bracketed text]` in page copy automatically.
- It shows on an amber `caution-tint` ground in mono type. Add `is-clean` to an ancestor (the site's "Highlight placeholders" switch does this) to see the page as a reader would.
- Say what is needed and its unit: "[capacity, L/h]", not "[TBD]".
- Before launch, every placeholder is either replaced with a confirmed fact or the sentence is removed. Agents must never fill one with a guessed value.
