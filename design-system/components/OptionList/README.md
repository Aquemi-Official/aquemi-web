OptionList shows configuration choices for a system in two columns separated by hairlines.

- Markup: `<div class="aq-options">` with one `<div>` per option holding `<span class="aq-h3">` and `<span class="aq-small">`.
- Use it for choices a buyer makes (sanitization method, capacity range, materials, controls), not for page links. For links use LinkGrid.
- Each description names the value or standard that decides the choice: "Hot water at 80 °C", "Ozone at 20–50 ppb".
- One column when the page is narrower than 860 px.
