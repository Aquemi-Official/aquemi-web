Router lets a buyer pick the situation they are in and see one route through what follows: the water they need, the system, and where to start with us.

- Data: a `table` block with `"as": "router"`. `cols`: the situation column, then one column per station ("Water you need", "System", "Start with"). `rows`: the situation, then one cell per station, a string or `{t, link}`.
- Markup (`blocks/router.js`): `.aq-router` holds, per row, a `button.aq-router__opt` (`.aq-index`, `.aq-router__t`, `aria-expanded`, `aria-controls`) followed by its `.aq-router__route` (an `ol.aq-router__stations` of `li` > `.aq-router__k` label + `.aq-router__v` value). One route is open at a time, the first by default; closed routes stay in the markup with `hidden`.
- Drawn on a Plate (`wPlate`, title block Aquemi | nav | N routes). Desktop: situations as rows on the left with a large light mono index; the chosen one is a `flow-tint` tab in a `flow` frame with a node on its edge and a `flow` pipe with an arrowhead into the route frame. The route spans every row: framed stations, each with a mono "Station 0N" number and a header strip naming its column, joined by `flow` pipes with arrowheads. Phones: the route opens under its situation (a short arrowed riser from the tab), stations stacked with arrowed risers between them, the station number folded into the header strip.
- Links: the station with the last `{t, link}` cell (usually "Start with") is the end station (`li.is-go`: `flow` header, `flow-tint` body), and the whole route frame is clickable to that page (`.aq-router__route.is-link` holds `a.aq-router__hit`, a pointer-only overlay with `tabindex=-1` and `aria-hidden`; the real link in the station stays the keyboard and screen reader target). The situation button stays a toggle.
- Ground: the navy page (a visual anchor), never a light sheet.
- Use it when the first column of a table is "your situation" and the rest is what to do about it. For a comparison of two routes use Versus; for a plain lookup with no "where to start", CompareTable.
