ContactRoutes sets the ways into Aquemi as rows on hairlines, each with its own numbered 1 → 2 → 3 strip and response clock, so a visitor on a contact page sees which route fits before the form: request a proposal, production stopped (call the service line), or visit the shop.

Origin: `inspiration/gemini/62-concept-contact-routes.png`, set in the brand's plain style (the concept's blueprint frame, folder tabs, dashed route line and navy panel dropped).

- Data: block `"type": "contact-routes"` with `routes: [{t, d, steps: [3 strings], clock, link, phone?, urgent?, current?, action?, intent?}]`. `link` is a page id. `clock` is the full response line ("Written reply within [proposal response time, working days]"); every time stays the page's own placeholder until Aquemi confirms it. `action` overrides the button label (default: the linked page's nav label); `intent` ticks options on that page's form, as on Button.
- Rows: the routes stack full width on the page ground, separated by 1 px `line` hairlines (and one under the last). Each row: an eyebrow line (`aq-contact-routes__tab`: "Route N" in data order, then "· Urgent" and/or "· This page", mono 12/16, 0.08em, uppercase, `ink-muted`); a head with the title (`h2` scale, 28/34 Geist 400) and one line on the left and the response clock and the action on the right (3 : 2); a step strip along the foot under a hairline: three steps, each a mono number in `ink-subtle` and the step in Geist 15/22, an arrow between them.
- Current route: `current: true` (or `link` equal to the page being read) turns the row's top hairline `flow`, colours "This page" `flow`, sets `aria-current="page"` and turns its action into a primary jump to this page's form (the form block's `nav` id; without one, the first form on the page). The other rows link to their pages with a secondary button.
- Urgent route: `urgent: true` sets the row on a quiet `limestone` panel (`data-theme="light"`, so its text and secondary button keep the light tokens in both themes) with a call line under a `line-strong` hairline: phone icon, "Call" eyebrow, the number in mono 300 at 40/44 (28/34 on phones); once the number is real it becomes a `tel:` link. The urgent row is first in the markup, so phones show it first and it is never hidden; desktop keeps the data order through `--o`. One urgent route per block.
- Markup (`blocks/contactroutes.js`): `ul.aq-contact-routes` of `li.aq-contact-routes__route` (`is-current`, `is-urgent`, inline `--o`): `p.aq-contact-routes__tab` (`__rn`, `__mark`), `.aq-contact-routes__head` (`__main`: `h3.__t`, `p.__d`; `__side`: `p.__clock` with icon, `__k` "Response", `__v`; `.__action`), `p.aq-contact-routes__call` (icon, `__k`, `__num`), `ol.aq-contact-routes__steps` (`li`: `.__n` aria-hidden, `.__s`, `.__arrow` "→" aria-hidden).
- Phones (`@container (max-width: 860px)`): rows stack urgent first, ordinary rows flush to the content edge, the urgent panel with `space-4` padding; the head opens up so the call line sits right under the urgent title, above the clock and the action; steps stack one per line (14/22), no arrows. Every label is 12 px or more; buttons are 44 px tall.
- No boxes, folder tabs, route lines, rings, shadows or navy panels.
- Keep it to three routes and three short steps each. Not for a list of related pages (RelatedLinks) or for choosing a technical route by situation (Router).

## Motion

Motion (`motion.js`): the dashed route line grows down the left (`--aq-riser`); each sheet slides in, its stub runs out from the line and the arrowhead lands (`--aq-stub`), the folder tab rises, the head and call bar settle, then the 1 > 2 > 3 strip runs: the dashed line draws (`--aq-line`) and each ring pops as it arrives. The urgent dot pulses twice (1.2 s) and stops. Desktop: one timeline in data order (under 4.4 s); phones: each sheet as it scrolls in, urgent first. Variables default to 1 in the CSS.
