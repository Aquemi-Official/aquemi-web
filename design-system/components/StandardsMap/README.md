StandardsMap is a plant map of the water system: each zone (generation, storage and distribution, pure steam, controls and data, fabrication, qualification) is a framed area labelled with the standards that govern it, and every code jumps to the row further down the page that proves it.

- Data: block `"type": "standards-map"` with `zones: [{t, codes, to, spot, icon}]`. `to` is the id of the section holding the proof (give that block an `anchor`, or use its nav id `s-N-label`); the zone title jumps there. `codes` are strings as the rows write them ("USP <645>", "EU GMP Annex 1"); a code may be `{t, to}` to point at another section. `spot` is a Spot name (`assets/spots/`), the zone's equipment vignette (generation `ro-skid` or `pretreatment`, storage and distribution `storage-tank`, pure steam `pure-steam-generator`, controls and data `control-panel`, fabrication `orbital-welder`, qualification `signed-report` or `binder-docs`); all or none. Without spots, `icon` is an Icon name, used only when every zone has one (otherwise the `01` index).
- Markup (`blocks/standardsmap.js`): with spots, `wPlate(…, {cls:"aq-standards-map__plate"})` around `.aq-standards-map.aq-standards-map--spots`; each zone then starts with `span.aq-standards-map__fig` (aria-hidden, Spot `aq-standards-map__spot`) before `.aq-standards-map__label`. Otherwise `.aq-standards-map` > `ol.aq-standards-map__zones` (grid; `::before` is the pipe, `::after` its arrow) > `li.aq-standards-map__zone.is-up|is-down` > `.aq-standards-map__label` > `.aq-standards-map__head` (Icon `aq-standards-map__icon` or `aq-index`, `h3.aq-standards-map__t` with the section link) and `ul.aq-standards-map__codes` of `a.aq-standards-map__code` (`data-smap-code`, `data-smap-to`).
- Jump: a code chip scrolls to the row naming it (EvidenceMap rows matched on their title, spec and table rows cell by cell, whole-code match so "Annex 1" never lands on "Annex 15"), first in the zone's section, then anywhere on the page. A folded row is unfolded first; the row takes focus and flashes a `flow` outline once (`.aq-standards-map-hit`, no animation under reduced motion).
- With spots (the plant drawing): the map sits on a plate (hairline frame, ruler ticks, registration crosses) over a faint `line` drawing grid; each zone is a dashed `line-strong` plant area with its 128 px vignette in `on-navy-muted` (`flow` on hover), the name in 14/20 uppercase mono and the codes beside it on a dashed `line-strong` leader, a dashed `flow` leader with a node from the vignette to the name. The zones hang off a 1 px dashed `flow` main (arrow at the end) by dashed `flow` branches. Phones: zones stacked on a vertical dashed main at the left, the vignette (96 px) at each zone's right, name and code chips running beside and under it.
- Without spots, desktop: the first half of the zones above a `flow` pipe header (2 px, arrow at the end), the rest below, each zone a 1 px dashed `line-strong` frame with a `flow` branch and node to the pipe. Codes are mono chips in a 1 px `line-strong` frame with a quiet ↓, `flow` on hover. Phones: zones stacked as compact rows on a vertical pipe at the left, codes wrap as chips.
- Ground: the navy page (a visual anchor ahead of the evidence sheets it indexes). Use only standards the page already lists, each pointing at a row that exists; three to six zones.
- When not to use it: a page citing fewer than about eight standards (a StandardsGrid or the rows themselves say it), or standards with no rows to prove them on the same page.

## Motion

`motion.js`: the plant is piped up in flow order. The main header draws left to right (top to bottom on phones); as it passes each zone a node seats, the branch grows out, the zone's dashed area opens from the pipe side, its vignette prints in, the leader runs to the name, the name lands and the code chips follow; the arrow lights last (about 3 s). Pipe, branches, nodes and leaders are pseudo-elements drawn through `--aq-pipe`, `--aq-arrow`, `--aq-branch`, `--aq-node`, `--aq-lead` (scale and opacity only; unset they are 1, so the map is whole without JS). Chips give a 1 px press.
